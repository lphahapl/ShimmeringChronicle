# 宵宫材质

宵宫.fbx 的 27 个材质槽已按原模型材质名称建立外部映射：面部使用面.png，头发/头饰/眼睛使用髮.png，服装/配饰使用衣.png，皮肤使用肌.png。

普通部位使用 URP/Lit、双面和透明裁切，保留原有手绘颜色。10._sph+ 是重叠的头发高光几何，使用加法混合，黑色背景不会遮住头发。

Yoimiya_URP.prefab 是已经配置材质的预制体。FBX 导入映射也已保存，因此重新拖入宵宫.fbx 同样会带上材质。本次没有修改动画、骨骼或替换场景角色。

菜单 Tools > Art > Upgrade Falcon and Bind Yoimiya 可重建映射。此命令会重新设置这些生成的材质参数。
