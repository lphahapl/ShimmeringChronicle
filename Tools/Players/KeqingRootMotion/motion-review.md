# 刻晴动作复查

本次复查仅修改新刻晴玩家。原玩家脚本、原动作、原控制器和刻晴 FBX/导入设置保持不变。

旧版本的问题是手腕直接追随剑刃方向，忽略 MMD 手掌与前臂的骨骼方向；固定肘部弯曲方向令摆臂僵硬；脚掌滚动没有补偿鞋底高度；收步与转身没有保持支撑脚落点。之前的 Play Mode 检查只覆盖根运动和连击功能，没有覆盖这些姿态问题。

| 动作 | 检查与修正 |
| --- | --- |
| Idle | 使用原 1A 的准备姿态重映射上身，放松手臂，保留轻微呼吸；握剑方向与掌骨一致。 |
| Walk / Run | 参考原动作的肩肘和上身运动；支撑脚轨迹匹配根位移，实际鞋底高度随脚掌滚动修正。走跑切换保留相位。 |
| WalkStart / RunStart | 对准备姿态与步态作骨骼插值，根速度逐渐增加，避免第一帧直接开始匀速滑动。 |
| WalkStop / RunStop / StopRight | 增加左右脚领先的收步版本，按实际脚的位置选择，逐渐减速并回到准备姿态。 |
| TurnLeft / TurnRight | 根旋转 90°，左右脚分阶段迈步；支撑脚保持世界落点和朝向。 |
| Attack1 / Attack2 / Attack3 | 参考原 1A/2A/3A 的肩肘、身体转动与收势；校正剑柄、限制手腕反折与异常转速；第三段改为前踏直刺。延后连击衔接，避免从挥击中途跳回下一段准备姿态。 |

全部 14 段动作均按 120 Hz 检查手腕、转身支撑脚与剑尖高度，并按 60 Hz 检查实际蒙皮网格的最低顶点。最终手腕最大折角约 38°，剑尖最小离地约 13 cm，转身支撑脚最大水平滑动约 0.9 mm。手指按掌骨的正确弯曲轴握剑。曾审核正面/侧面各五个关键时刻与握剑近景；过程截图已清理，保留最终动作预览。

`naturalness-after.txt` 为最终复验结果；旧失败日志已清理。检测鞋底时使用实际网格顶点，Unity 的 BakeMesh 缓存包围盒可能较大，不作为鞋底触地证据。

真实 Play Mode 的循环、根速度、起停、转身、输入缓存、三段命中事件、收势及墙体碰撞结果保存在 `validation.txt`。这些检查用于排除已定位的问题，具体动作观感仍可在独立预览场景中逐段查看。
