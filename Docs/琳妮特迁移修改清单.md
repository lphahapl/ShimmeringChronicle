## 新增 MoveStart 状态检查

你新增的起步状态已同步进琳妮特的覆盖配置，目前能继续运行，但配置还不完整：

- `MoveStart -> Move` 的 Has Exit Time 未启用，IsMove 在进入起步时已经为 true，因此会立即开始 0.05 秒混合，Exit Time 的 0.7 当前不生效。
- 若启用等待退出，需要为 MoveStart 增加攻击、闪避、转身出口；当前只有移动和待机出口。否则起步期间的攻击和闪避会延迟，转身时还可能找不到可用出口。
- 松开移动返回待机的条件为 IsMove=false 且 IsTurning=false，这条可用。

本次仅检查该状态，保留你当前的连线与参数，未擅自改动它。
